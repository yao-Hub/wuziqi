# 五子棋联机版

一个基于 Vue 3、Vite 和 WebSocket 的局域网双人在线五子棋项目。

## 功能

- 创建或加入房间，使用 4 位数字房间号
- 黑棋先手、白棋后手，并校验双方落子回合
- 自动判断横向、纵向及两个斜向的五子连线
- 支持向对手发起悔棋申请
- 一局结束后可重新开始
- 服务端自动返回局域网 IP 和 WebSocket 地址

## 环境要求

| 依赖 | 版本 |
| --- | --- |
| Node.js | 20.19+ 或 22.12+ |
| npm | 随 Node.js 安装 |
| 浏览器 | 支持 WebSocket 的现代浏览器 |

两个玩家需要处于同一局域网，或能够互相访问运行服务端的机器。

## 快速开始

先在两个终端分别启动服务端和前端。

### 1. 启动服务端

```bash
cd gobang-server
npm install
node server.js
```

启动成功后，终端会显示类似信息：

```text
局域网IP: 192.168.1.10
HTTP接口地址: http://192.168.1.10:9000/ip
WebSocket连接地址: ws://192.168.1.10:9000
```

服务端同时提供以下两个端点：

| 端点 | 用途 |
| --- | --- |
| `http://<服务端IP>:9000/ip` | 查询服务端局域网 IP 和 WebSocket 地址 |
| `ws://<服务端IP>:9000` | 房间和对局 WebSocket 连接 |

### 2. 启动前端

在另一个终端执行：

```bash
cd gobang-client
npm install
npm run dev
```

浏览器打开 Vite 输出的地址，默认为：

```text
http://localhost:5173
```

## 联机对战

1. 确保两台设备连接同一局域网，并启动服务端和前端。
2. 在“服务端配置”中输入服务端的 IP 和端口，例如 `192.168.1.10:9000`。
3. 点击“连接服务端”。连接成功后，页面会显示 WebSocket 地址。
4. 玩家一点击“创建新房间”，系统会生成一个 4 位房间号。
5. 玩家二在“可用房间”中选择房间，或输入房间号后点击“加入房间”。
6. 两名玩家进入棋盘后即可开始对局，创建房间的玩家执黑先手。

如果在另一台设备上访问前端，需要在玩家二设备中打开前端所在机器的局域网地址，例如：

```text
http://192.168.1.10:5173
```

不要在其他设备上使用 `localhost` 访问另一台机器。

## 对局操作

| 操作 | 说明 |
| --- | --- |
| 落子 | 轮到自己时，点击棋盘交叉点放置棋子 |
| 悔棋 | 等待对方落子时，对对手的上一手发起悔棋申请，对方同意后撤销 |
| 再来一局 | 任意一方在游戏结束后点击即可重置棋盘 |
| 返回首页 | 离开当前房间并返回房间列表 |

任意方向率先连成五颗或更多同色棋子的一方获胜。

## 构建前端

```bash
cd gobang-client
npm run build
npm run preview
```

构建产物位于 `gobang-client/dist/`。该目录默认不会提交到 Git。

若部署到其他静态服务器，需要支持 Vue Router 的 SPA 路由回退，并确保页面能够访问 WebSocket 服务端。

## 常见问题

### 无法连接服务端

- 确认 `node server.js` 仍在运行。
- 确认输入的 IP 和端口是服务端所在机器的局域网地址，而不是另一台设备的地址。
- 确认两台设备处于同一网络，并使用 `http://<服务端IP>:9000/ip` 测试连接。
- 在服务端机器上允许 Node.js 通过防火墙，或放行 TCP `9000` 端口。

### 其他设备无法打开前端

- 前端开发服务器已配置监听 `0.0.0.0`，请使用前端机器的局域网 IP 访问。
- 在防火墙中放行 Vite 使用的端口，默认是 TCP `5173`。
- 部分公共 Wi-Fi 开启了客户端隔离，设备之间无法互相访问，可改用家庭网络或手机热点。

### 房间列表为空

房间列表只显示仍在等待第二名玩家的房间。房间人数已满或游戏已开始时，需要直接使用房间号加入对应房间。

### 修改服务端端口

当前端口在 `gobang-server/server.js` 中设为 `9000`。如有冲突，可在该文件中修改 `PORT`，并同步修改前端的服务端配置。
